## 初始化中处理的问题

- 首次环境缺少 Flutter、Android SDK 和模拟器，已先报告，再在 `.tools` 中安装所需工具。
- 根据 Flutter 3.50 SDK 指引，界面使用 `material_ui` 替代已弃用的 `flutter/material.dart` 导入，并调整不再支持 `const` 的构造调用。
- 新版 Android SDK 管理器在自动安装 NDK 时错误拆分包名，使用新版 Android CLI 的 `ndk/28.2.13676358` 路径显式安装指定组件。
- 开发脚本使用普通参数转发，避免 PowerShell 将 Flutter 的 `-v` / `-d` 参数当作自己的通用参数。
- 首次构建下载 Kotlin 编译器时连接停顿，从相同 Maven 官方地址下载指定版本，校验 SHA-1 与官方值一致后补入本地缓存，重新构建成功；没有修改依赖版本或替换依赖来源。

## 运行方法

在项目根目录打开 PowerShell，连接 Android 手机或启动项目模拟器后运行：

```powershell
.\scripts\dev.ps1 devices
.\scripts\dev.ps1 run -d emulator-5554
```

真机使用 `devices` 返回的设备 ID。完整步骤见根目录 `README.md`。
